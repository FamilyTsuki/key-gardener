## 1. Gestion de votre Compte (Obligatoire)

Pour profiter de l'expérience complète et accéder au jeu, la création d'un profil est requise.

### Inscription et Connexion
- Rendez-vous sur la page d'accueil et cliquez sur **S'inscrire**.
- Remplissez les champs requis (Pseudo, Email, Mot de passe). 
- Une fois votre compte créé, utilisez l'onglet **Se Connecter** pour accéder à votre session sécurisée. Cela débloquera l'accès à vos sauvegardes cloud et au Hub Communautaire.

### Mot de passe oublié
- Si vous avez perdu vos identifiants, cliquez sur "Mot de passe oublié ?" sur la page de connexion.
- Entrez votre adresse email pour recevoir un lien sécurisé et chiffré vous permettant de réinitialiser instantanément votre mot de passe.

## 2. Fonctionnalités Web (Le Hub)

### La Page d'Accueil
C'est votre point d'entrée. Elle présente l'univers du jeu et ses mécaniques grâce à un arrière-plan 3D immersif en temps réel.

### Le Hub Communautaire
C'est le réseau social intégré à l'application. Accessible depuis le menu principal une fois connecté, le Hub vous permet de :
- **Publier des messages** : Partagez vos meilleurs scores, vos astuces de survie ou demandez de l'aide.
- **Interagir** : Lisez les messages des autres joueurs en temps réel. Le Hub est conçu pour créer une forte communauté autour de la frappe au clavier et rompre l'isolement du mode solo.

> [!NOTE]
> **Modération IA :** Tous les messages sont automatiquement filtrés par un modérateur Intelligence Artificielle (Gemini) afin de garantir un environnement communautaire sûr et respectueux.

## 3. Le Jeu : Lancement et Mécaniques

### Démarrer une Partie
1. Cliquez sur **Play** depuis la page d'accueil ou naviguez vers le menu **Saves** (Sauvegardes).
2. Le système vous propose **3 emplacements de sauvegarde** distincts (synchronisés dans le cloud via votre compte).
3. Choisissez un emplacement pour reprendre votre progression ou commencer une nouvelle descente dans le réseau.

### Comment Jouer ? (Les 3 Phases)

> [!IMPORTANT]
> Le jeu se contrôle **entièrement au clavier**. La souris est complètement inutile une fois la partie lancée.

Le gameplay est divisé en trois phases distinctes :

#### 1. Phase d'Exploration (Le Couloir)
- Le sol est composé de dalles représentant votre clavier physique.
- **Action** : Frappez la touche correspondante sur votre vrai clavier pour faire avancer votre personnage.

#### 2. Phase d'Événements (Events)
- Vous ferez face à des événements aléatoires bloquant votre chemin.
- **Action** : Ces événements peuvent prendre la forme de mini-jeux de frappe, de tests de vitesse ou de défis chronométrés. Réussissez-les pour avancer.

#### 3. Arène de Survie & Boss
- L'environnement 3D se transforme pour correspondre exactement à la disposition de votre clavier physique.
- **Déplacement** : Appuyez sur n'importe quelle touche pour vous téléporter instantanément sur la case correspondante.
- **Combat (Sorts & Arbre de Compétences)** : Les sorts ne sont pas tous disponibles dès le début. Vous devez les débloquer et les améliorer via l'**Arbre de Compétences (Skill Tree)** accessible entre vos parties. Une fois équipés, tapez les mots complets pour attaquer ou vous défendre :
  - `FIRE` : Lance un projectile offensif sur les virus.
  - `HEAL` : Restaure 15 Points de Vie.
  - `CIRCLE` : Invoque un mur de feu défensif autour de vous.

## 4. Prérequis Techniques & Dépannage

> [!WARNING]
> Cette application s'appuie fortement sur des technologies 3D avancées (WebGL) pour le rendu du monde du jeu.

- **Navigateur** : Utilisez un navigateur moderne (Google Chrome, Mozilla Firefox, ou Microsoft Edge).
- **Accélération Matérielle** : Assurez-vous que l'accélération matérielle est **activée** dans les paramètres de votre navigateur pour garantir une fluidité à 60 FPS.
- **Problème d'Affichage** : Si une animation saccade ou qu'un menu se fige, rafraîchissez simplement la page (`F5` ou `Ctrl + F5`).
