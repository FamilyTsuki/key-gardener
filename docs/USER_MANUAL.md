# 📖 Documentation Utilisateur : Keyboard Survivor

Bienvenue dans la documentation officielle de **Keyboard Survivor**. Ce guide a pour but de vous expliquer clairement le fonctionnement de l'application web et de ses différentes fonctionnalités, tout en vous préparant à l'aventure qui vous attend.

---

## 👤 1. Gestion de votre Compte (Obligatoire)
Pour profiter de l'expérience complète et accéder au jeu, la création d'un profil est requise.

### Inscription et Connexion
- Rendez-vous sur la page d'accueil et cliquez sur **S'inscrire**.
- Remplissez les champs (Pseudo, Email, Mot de passe). 
- Une fois votre compte créé, si vous êtes déconnecté, utilisez l'onglet **Se Connecter** pour accéder à votre session sécurisée. Cela débloquera l'accès à vos sauvegardes et au Hub communautaire.

### Mot de passe oublié
- Si vous avez perdu vos identifiants, cliquez sur "Mot de passe oublié ?" sur la page de connexion.
- Entrez votre adresse email. Vous recevrez un lien sécurisé permettant de réinitialiser instantanément votre mot de passe.

---

## 🌐 2. Les Fonctionnalités du Site (L'Application)

### La Page d'Accueil
C'est votre point d'entrée. Elle présente l'univers du jeu et ses mécaniques grâce à de la 3D immersive.

### Le Hub Communautaire
C'est le réseau social intégré à l'application. Accessible depuis le menu principal une fois connecté, le Hub vous permet de :
- **Publier des messages** : Partagez vos scores, vos astuces de survie ou posez des questions.
- **Interagir** : Lisez les messages des autres joueurs en temps réel. Le Hub est conçu pour rompre l'isolement entre deux parties.

---

## 🎮 3. Le Jeu : Lancement et Mécaniques

### Lancer une partie
1. Cliquez sur **Play** depuis la page d'accueil (home) ou depuis le menu **Saves** de navigation.
2. Le système vous proposera **3 emplacements de sauvegarde** distincts (sauvegardés dans le cloud lié à votre compte).
3. Choisissez un emplacement pour reprendre votre progression ou commencer une nouvelle descente.

### Comment jouer ? (Les 3 Phases)
Le gameplay se déroule entièrement au clavier (la souris est inutile en jeu) et se divise en trois moments :

1. **La Phase d'Exploration (Le Couloir)** : 
   - Le sol est composé de dalles représentant votre clavier.
   - **Action** : Frappez la touche pour avancer.

2. **Les Events** :
   - Vous ferez face à divers events, vous pourrez les réussir ou échouer.
   - ils peuvent prendre bocoup de forme comme des minigame ou des chronometre

3. **L'Arène de Survie & Les Boss** :
   - L'environnement devient la grille de votre clavier physique.
   - **Déplacement** : Appuyez sur une touche pour vous téléporter sur sa case.
   - **Combat (Sorts)** : Tapez des mots complets pour attaquer ou vous défendre :
     - `FIRE` : Lance un projectile sur les virus.
     - `HEAL` : Vous rend 15 Points de Vie.
     - `CIRCLE` : Invoque un mur de feu défensif.

## ⚙️ 4. Prérequis Techniques & Dépannage
L'application utilise des technologies 3D avancées (WebGL) pour le rendu du jeu.
- **Navigateur** : Utilisez un navigateur récent (Google Chrome, Mozilla Firefox, ou Microsoft Edge).
- **Accélération Matérielle** : Assurez-vous qu'elle est **activée** dans les paramètres de votre navigateur pour que le jeu soit fluide.
- **Problème d'affichage** : Si une animation ou un menu reste bloqué, rafraîchissez simplement la page (ctrl + F5).
